GUIA RAPIDA DE INTEGRACION CON MALTEGO DESKTOP:
  1. Descarga el archivo de configuracion maltego-mcp-config.mtz pulsando el boton superior.
  2. Abre tu aplicacion Maltego Desktop (Classic, XL o Community).
  3. Navega al menu superior: Manage → Import → Import Config.
  4. Selecciona el archivo maltego-mcp-config.mtz y pulsa Next → Finish.
  5. Los transforms del servidor local apareceran automaticamente listados bajo la categoria MCP Maltego en el panel de transforms.
